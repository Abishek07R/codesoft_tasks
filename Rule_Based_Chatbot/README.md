# Rule-Based Chatbot

## Description
This project is a simple chatbot developed using Python. It responds to user inputs using predefined rules implemented with if-elif-else statements.

## Features
- Greets the user
- Answers basic questions
- Displays current date
- Displays current time
- Responds to thanks
- Exits on "bye"
- Handles unknown inputs

## Technologies Used
- Python 3

## How to Run
1. Install Python.
2. Open terminal.
3. Run:
   python chatbot.py
